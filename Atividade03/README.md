# CadastroAlunoHTML_web

Este projeto tem como finalidade desenvolver interfaces gráficas web utilizando HTML, CSS e JavaScript, com foco em cadastro e gerenciamento de alunos. A atividade também envolve o uso de uma IDE (NetBeans) e o versionamento de código com GitHub.

##🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- NetBeans IDE
- GitHub

## 📁 Estrutura do projeto

- `index.html` – Menu principal com links para as interfaces
- `FrmCadastroAluno.html` – Interface para cadastrar alunos
- `FrmGerenciarAluno.html` – Interface para listar, editar e excluir alunos
- `estilo.css` – Estilos visuais aplicados às interfaces
- `biblioteca.js` – Funções JavaScript para validação e exibição de dados

## 🚀 Como executar

1. Abra o projeto no navegador usando o arquivo `index.html`.
2. Navegue pelas interfaces:
   - `FrmCadastroAluno.html` para cadastrar alunos
   - `FrmGerenciarAluno.html` para listar, editar e excluir alunos

## 📚 Exercícios propostos

- Criar interfaces com campos de entrada como nome, idade, curso e fase.
- Validar campos obrigatórios e permitir apenas números onde necessário.
- Exibir os dados cadastrados dinamicamente.
- Listar alunos em uma tabela com opções de edição e exclusão.
- Estilizar as páginas com CSS.
- Publicar o projeto na web usando Vercel.
- Realizar atividades complementares como:
  - Estudo sobre tabelas HTML e atributos como `BGCOLOR`
  - Diferença entre métodos GET e POST
  - Inclusão de imagens em tabelas
  - Cursos online de desenvolvimento web
