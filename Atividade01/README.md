# Fundamentos de Arquitetura Web

Este projeto reúne exercícios práticos sobre os principais conceitos da arquitetura web, com foco em HTML, CSS, JavaScript, protocolo HTTP e comunicação cliente-servidor. Os exemplos foram desenvolvidos com base em um material didático voltado para aplicações web em Java.

## 🧪 Estrutura dos Exercícios

Os exercícios estão organizados em arquivos separados, como:

- `index.html` — estrutura básica
- `formularioValidacao.html` — validação de campos
- `upload.html` — envio de arquivos
- `servidor_web_http_java_simples` — projeto Java com servidor HTTP básico
- `biblioteca.js` — validações em arquivo externo

## 🚀 Como Executar

1. Clone ou baixe este repositório.
2. Abra os arquivos `.html` diretamente no navegador para testar os exemplos.
3. Para o projeto Java:
   - Importe o projeto Maven no seu IDE (ex: VS Code ou IntelliJ).
   - Execute a classe principal para iniciar o servidor HTTP.
   - Acesse `http://localhost:8000/MensagemSimples` no navegador.
