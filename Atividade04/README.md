# Projeto Web Java com NetBeans 13 e Tomcat 9

Este projeto foi criado como parte das atividades de configuração e desenvolvimento de aplicações Web em Java, utilizando o Apache NetBeans IDE 13 e o servidor Apache Tomcat 9.

## 🧩 Tecnologias utilizadas

- Java EE 7
- Apache NetBeans IDE 13
- Apache Tomcat 9
- Maven (empacotamento WAR)

## 📦 Estrutura do projeto

- Projeto Maven com empacotamento WAR
- Servlet de exemplo
- Página JSP de exemplo
- Configuração de servidor Tomcat integrada ao NetBeans

## 🚀 Como executar

1. Certifique-se de que o Tomcat está configurado e iniciado no NetBeans.
2. Execute o projeto clicando com o botão direito → **Run**.
3. Acesse a aplicação via navegador em:  
   `http://localhost:8080/nome-do-projeto`

## 📚 Atividades realizadas

- Configuração do Tomcat no NetBeans
- Criação de projeto Web com Maven
- Implementação de servlet e JSP
- Execução e testes via Tomcat
- Verificação de logs e monitoramento HTTP
